# 夜航音乐工作室

安装：`npm install`

本地启动：`npm run dev`，访问终端显示的地址。

Docker 启动：`docker compose up --build -d`，访问 http://localhost:18027 。

类型检查：`npm run typecheck`　·　单测：`npm test`　·　构建：`npm run build`

## 人声录制

除鼓组与琴键外，可添加「人声音轨」用麦克风录制一段演唱，与现有循环一起播放。

- **设备与权限**：演奏台选中人声音轨后，在面板选择输入设备，旁边的状态灯实时显示
  麦克风权限（已授权 / 待授权 / 被拒绝）。点「重新授权」可再次发起浏览器授权；
  设备插拔会自动刷新列表。
- **循环边界对齐**：录音的开始与结束都落在拍钟决定的循环边界上（自动等到下一个整圈起点，
  录满一整圈结束）。采集设备时钟与演奏拍点存在偏差时，以实际录到的音频时间戳为准，
  对两端做静音补齐或裁切，输出始终是精确整数圈的采样数，因此每一圈等长、不会逐渐错位。
- **波形显示**：人声片段在编排区按峰值绘制波形，与鼓组 / 琴键轨道并列。
- **独立混音**：人声走该轨道自己的混音总线，可在混音台独立调节音量与静音。
- **监听默认关闭**：实时监听（麦克风直通扬声器）默认关闭以避免啸叫，需要时手动开启，建议戴耳机。
- **失败保留旧片段**：权限被拒绝、设备中途拔出或手动取消，都不会触碰已有片段；
  只有新片段完整采集、对齐、编码成功后才会替换。
- **保存与恢复**：音频以 WAV 存入 IndexedDB，作品元数据（含波形、引用）存入 localStorage，
  保存时两者一起写入。恢复时若某段音频缺失，只把该片段标记为「音频不可用」并在编排区明确标出，
  不会清空其他任何轨道。

## 目录结构

- `src/features/vocals` 人声采集（AudioWorklet，含 ScriptProcessor 回退）、
  边界对齐、WAV 编解码、IndexedDB 存储、循环播放器与相关 UI。
- `test/boundary.test.mjs` 边界对齐纯逻辑测试（补齐 / 裁切 / 防逐圈漂移）。
